<objective>
Wave 3: add the precision-gated interpretive tail and wire the phase gate. The tail reuses the
existing Phase-3 hand-rolled review loop on a Qwen producer to surface grounded deficiencies no
deterministic rule expresses; each is emitted through the byte-exact emit_finding grounding gate,
tagged with its producer family, and passed through the SAME consensus verifier (so a
Llama-inclusive decorrelated panel judges it). Finally, a verify-f1 gate proves verification + tail
does not lower end-to-end F1 and loses zero true positives vs. the frozen Phase-5 baseline.

Purpose: VERIFY-04 (interpretive tail) + the phase gate that grades the whole phase. The P3 NO-GO is
the governing caution — the tail is tightly budgeted, hard precision-gated, and disabled for a run
if it adds FPs the consensus verifier does not catch.

Output: src/verify/tail.py + a verify-f1 gate subcommand in evals/run.py + two Wave-0 tests
(test_tail_gate, a new test_verify_f1_gate) green. Includes a human-verify checkpoint for the
MAIN-tree live F1 measurement (gitignored corpus).
