Implement each op as an offset-tracked transform that emits `OffsetRun`s (`schemas.documents.OffsetRun`). A run is `(canon_start, canon_len, raw_start, raw_len, kind)`; unchanged spans are one big "equal" run; NFC compose = many→one (`compose`); whitespace collapse = many→one (`collapse`); dehyphen drop = raw_len>0,canon_len=0 (`delete`); ligature = canon_len>canon of raw (`expand`). Compose the four ops' maps into one canonical↔raw map over the ORIGINAL raw input (chain the intermediate maps; the `tokenizers.NormalizedString` reference at RESEARCH:151 may be used for the NFC leg but the composed map is your own).

Functions:
  - `def guarded_dehyphenate(text, is_plausible_word) -> tuple[str, list]`: copy RESEARCH:411-420 exactly (never drop after a digit; rejoin only if plausible; else keep hyphen + drop line break).
