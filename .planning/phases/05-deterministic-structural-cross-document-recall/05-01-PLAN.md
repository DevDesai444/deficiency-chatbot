issue_cached_span shared helper (Ruling 1 — the bridge between cache-derived spans and the emit gate):
```python
def issue_cached_span(
    ledger: RetrievalLedger,
    span_id: SpanID,
    nt: NormalizedText,
) -> SpanID | ToolRejected:
    """Record span in ledger (issuance) then verify byte-exact via open_span.
    Used identically by all three deterministic emit gates to satisfy ledger.was_issued().
    
    Replicates the Phase-4 pattern from absence.py:_emit_candidate:
      ledger.record_span(span) -> open_span(span, nt) -> return span
    The caller (emit gate) then calls ledger.was_issued(span_id) which returns True.
    """
    try:
        open_span(span_id, nt, span_id.doc_id)
    except HashMismatch:
        return ToolRejected(
            tool="issue_cached_span", reason_code="not_byte_exact", half="submission",
            reason="span_id does not re-open byte-exact against the corpus store",
            hint="re-fetch the current text and cite its freshly-issued span-ID",
        )
    ledger.record_span(span_id)
    return span_id
```
