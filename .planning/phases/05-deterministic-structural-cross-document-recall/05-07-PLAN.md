Edge key format (from references.py, Plan 04 canonical format):
```python
# src_id: f"{span.doc_id}:{span.start}"   — byte offset of the reference mention in the source doc
# dst_id: f"{dst_doc_id}:{dst_start}"     — byte offset of the referenced span in the target doc
# OR dst_id = "unresolved"                — if target span cannot be resolved at ingest time
```

B4 STRATEGY — concrete resolution (choose this one):
Option A (preferred): Add optional `span_start: int = 0` parameter to follow_reference.
When detect_reference_anomalies calls follow_reference for a known ref span, it passes span.start.
follow_reference constructs `src_key = f"{doc_id}:{span_start}"` and calls `get_edges(src_id=src_key, db_path=db_path)`.

Option B (fallback if get_edges doesn't support exact src_id match): query get_edges for all edges whose src_id starts with f"{doc_id}:", then filter by checking if the edge provenance JSON contains the ref_text.

In both options, if an edge is found with dst_id != "unresolved":
  - Parse dst_doc_id, dst_start from dst_id.split(":", 1)
  - Return {"doc_id": dst_doc_id, "resolved": True, "edge_type": edge_type, "label": ref_text, "status": "resolved_cross_doc"}
If no resolved edge found:
  - Return {"doc_id": doc_id, "ref_text": ref_text, "status": "UNRESOLVED_REF"}
The `cross_document_resolution_pending_phase_4` sentinel MUST NOT appear in the return path.
