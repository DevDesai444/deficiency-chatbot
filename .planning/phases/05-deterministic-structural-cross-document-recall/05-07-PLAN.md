```python
# After same-doc outline search fails to find a match:
# Step 1: Build src_key
if span_start is not None:
    src_key = f"{doc_id}:{span_start}"
    edges = get_edges(src_id=src_key, db_path=db_path)
else:
    import logging
    logging.warning("follow_reference: span_start not provided for doc_id=%s; scanning all doc edges", doc_id)
    all_edges = get_edges(src_id=None, db_path=db_path)  # or get all + filter
    edges = [e for e in all_edges if e[0].startswith(f"{doc_id}:")]

# Step 2: Find a resolved edge
for edge in edges:
    src_id, dst_id, edge_type, provenance_json = edge
    if dst_id and dst_id != "unresolved":
        dst_doc_id, dst_start_str = dst_id.split(":", 1)
        return {
            "doc_id": dst_doc_id,
            "resolved": True,
            "edge_type": edge_type,
            "label": ref_text,
            "status": "resolved_cross_doc",
        }

# Step 3: No resolved edge found
return {"doc_id": doc_id, "ref_text": ref_text, "status": "UNRESOLVED_REF"}
# DO NOT return: {"status": _CROSS_DOC_PENDING}
```

| Edge table src_id lookup | follow_reference reads from a SQLite edges table written by the reference extractor; the src_id is developer-controlled (derived from byte offsets in parsed documents — not from untrusted input at query time) |
| db_path parameter | Passed by calling code; points to a SQLite file on the local filesystem; not user-supplied at the HTTP boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05W5-01 | Tampering | Edge dst_id parsed and used as dst_doc_id in follow_reference return | mitigate | dst_doc_id is only used to build a return dict; no file I/O is done with dst_doc_id in follow_reference itself. The caller (references.py) validates the doc_id against the manifest before emitting a Fault. |
| T-05W5-02 | Elevation of Privilege | span_start=None default → may load all edges and filter in Python | mitigate | When span_start is None, follow_reference logs a warning and scans all doc edges. At worst returns UNRESOLVED_REF, never incorrect findings. Calling code (references.py) always passes span_start when it has the span. |
| T-05W5-03 | Tampering | db_path parameter passed as str — no path traversal protection | accept | db_path is always constructed by the internal pipeline (not from user input at any HTTP boundary). The database contains only edge metadata (no submission text), reducing the impact of path manipulation. |
