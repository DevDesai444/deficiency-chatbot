For FAISS cosine score retrieval: import faiss and numpy; use _ensure_faiss() to load the index; directly call `faiss_index.search(query_vec.reshape(1,-1), top_k*3)` to get distances (= cosine for IndexFlatIP with L2-normalized vectors). Map distances to [(doc_id, score)] using _faiss_doc_ids. This gives accurate per-chunk cosine scores for threshold comparison.

```python
# Direct FAISS query for accurate scores (avoids _rulebook_search_local which drops scores):
def _search_rulebook_faiss_with_scores(query_text: str, top_k: int) -> list[tuple[str, float]]:
    from rulebook.store import _ensure_faiss, _faiss_index, _faiss_doc_ids
    _ensure_faiss()
    if _faiss_index is None:
        return []
    qv = embed_query(query_text).reshape(1, -1).astype("float32")
    distances, indices = _faiss_index.search(qv, top_k)
    results = []
    for dist, idx in zip(distances[0], indices[0]):
        if idx < 0 or idx >= len(_faiss_doc_ids):
            continue
        doc_id = _faiss_doc_ids[idx]
        results.append((doc_id, float(dist)))  # IndexFlatIP: dist = cosine for L2-normalized
    return results
```
