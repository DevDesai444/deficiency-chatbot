Ruling 5 — Table primitive algorithm (CONCRETE specification):
The table_index in corpus cache has keys "{table_id},{row},{col}" mapping to SpanID.
Given a table, the algorithm must:

1. Build table shape: collect all (row, col) pairs for each table_id
2. Determine dimensions: max_row = max(r for r,c in cells), max_col = max(c for r,c in cells)
3. For each cell: read the text from corpus.cached_entry via SpanID
4. Label-cell vs value-cell pairing:
   - A cell is a "label candidate" if its text (stripped, lowercased) is in AGGREGATE_LEXICON
   - For a label candidate at position (r, c):
     * If r == max_row (last row): label is a ROW-AGGREGATE (aggregates the column above it)
       → basis cells: {(row, c) for row in range(0, r) if (row, c) in cells and row != r}
       → relation: infer from label (SUM→"total"/"sum", MAX→"maximum"/"max", MIN→"minimum"/"min", MEAN→"average"/"mean")
     * If c == max_col (last column): label is a COL-AGGREGATE (aggregates the row to its left)
       → basis cells: {(r, col) for col in range(0, c) if (r, col) in cells and col != c}
5. Open each basis cell text via corpus.cached_entry; parse as float; collect numeric_values
6. Compute recomputed = sum/max/min/mean(numeric_values)
7. Open label cell text; parse the numeric part
8. Apply D-STR4 precision-derived comparator: compare at min(precision(label_text), precision(recomputed_str))
9. If violation: build StructuralAnchor with claim_span_id=label_span, basis_span_ids=basis_spans, relation, expected_value=str(recomputed), actual_value=label_text
10. Call emit_structural_finding(corpus, rule_span_id=None, structural_anchor=anchor, ledger=ledger)

IMPORTANT — basis cell identification is by COLUMN (for row-aggregate) or ROW (for col-aggregate), NOT "same column as label." For the two-column table "Impurity | % w/w":
- Column 0 = Impurity names ("Compound A", "Compound B", "Total Impurities")
- Column 1 = Values ("0.10%", "0.18%", "0.12%")
- "Total Impurities" at (row=2, col=0) is in column 0 (labels column)
- The VALUE for "Total Impurities" is at (row=2, col=1) = "0.12%" — this is the CLAIM cell
- Basis value cells: (row=0, col=1) = "0.10%", (row=1, col=1) = "0.18%"
- So the algorithm must recognize "Total Impurities" as the label and look up the VALUE in the SAME ROW (col=1)

The general paired-column pattern:
- For a table with a label column (col=0) and value column (col=1): the aggregate label is in col=0, the aggregate value is in col=1 of the same row. The basis values are also in col=1 for all non-aggregate rows.
- Algorithm variant: look for cells in col=0 whose text is in AGGREGATE_LEXICON; the CLAIM cell is at (same_row, value_col) where value_col = col of numeric values; basis = all (non-aggregate-row, value_col) cells.

```python
def _find_value_column(cells: dict[tuple,str]) -> int | None:
    """Find the column index whose cells contain mostly numeric text (the value column)."""
    col_numeric_count: dict[int, int] = defaultdict(int)
    for (r, c), text in cells.items():
        if re.search(r'[\d.]+', text):
            col_numeric_count[c] += 1
    if not col_numeric_count:
        return None
    return max(col_numeric_count, key=col_numeric_count.get)

def _find_aggregate_rows(cells: dict[tuple,str]) -> list[int]:
    """Find rows whose label column (col=0) text is in AGGREGATE_LEXICON."""
    agg_rows = []
    for (r, c), text in cells.items():
        if c == 0 and text.strip().lower() in AGGREGATE_LEXICON:
            agg_rows.append(r)
    return agg_rows
```
