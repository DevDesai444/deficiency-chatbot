Full resolution pipeline for VALUE_CONTRADICTION detection:

```python
def _resolve_edge_value_contradiction(
    corpus: CorpusIndex,
    src_span_id: SpanID,
    src_text: str,        # text of the referencing span (contains the limit "NMT 0.15%")
    dst_doc_id: str,
    dst_span_id: SpanID | None,  # resolved target span if known
    edge_type: str,
) -> tuple[bool, Literal["full","low"]]:
    """
    Returns (is_contradiction, scoping_confidence).
    
    Step 1 — Extract limit from src_text:
    Match NMT/≤/limit patterns: re.search(r'NMT\s*([\d.]+%?)', src_text) or
    re.search(r'(?:limit|specification|spec)[:\s]*([\d.]+%?)', src_text, re.I)
    If no limit found: return (False, "low")  # cannot verify
    
    Step 2 — Identify the referenced entity (e.g., "single impurity", "Compound B"):
    If dst_span_id is resolved: open dst span, read text
    Else: search dst doc's table cells for text near the reference label
    
    Step 3 — Target table selection in dst doc:
    Load table_index from corpus.cached_entry(dst_doc_id)
    For each table: find cells where col=0 text matches the referenced entity name
    (e.g., find row where col=0 == "Compound B" and check col=1 value)
    
    Step 4 — Label matching:
    For each candidate row: check if value-column cell text is a numeric value
    that can be compared to the src limit
    
    Step 5 — Unit compatibility:
    Extract units from src (e.g., "%") and dst value (e.g., "%" or "% w/w")
    If units incompatible: abstain (return (False, "low"))
    Strip units before numeric comparison
    
    Step 6 — Compare using compare_values:
    is_violation = compare_values(dst_value_text, src_limit_text, "LEQ")
    # True = dst exceeds the NMT limit stated in src
    
    Confidence rules:
    - edge_type == "hyperlink" or "textual_ref" AND dst_span_id resolved: "full"
    - label-match-only (no edge, or dst_span_id unresolved): "low"
    """
```
