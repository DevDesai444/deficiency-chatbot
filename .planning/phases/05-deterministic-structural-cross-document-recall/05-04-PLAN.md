| edges.py SQLite write from reference extractor | Edge records written by the reference extractor; later read by follow_reference |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05W2B-01 | Tampering | Malicious hyperlink target URI in DOCX rels | mitigate | reference extractor stores the target URI as a string but NEVER resolves/fetches it. No SSRF risk. |
| T-05W2B-02 | Tampering | Regex injection via crafted canonical text | mitigate | _REF_PATTERNS use re.compile with fixed patterns; not constructed from user input. No injection risk. |
| T-05W2B-03 | Tampering | Forged edge provenance in SQLite (tampered edges.db) | mitigate | Provenance_span_id validated at emit_reference_finding call time via open_span HashMismatch check. |
| T-05W2B-04 | Denial of Service | Corpus with 100k cross-reference patterns (runaway regex) | mitigate | Cap total edges extracted per doc at 1000; log warning when cap is hit. |
