<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Per-submission index load (D-R5B) | Loading .embeddings.npy (numpy binary), .chunks.json, .bm25.json from disk — potential deserialization surface |
| Sidecar path construction | Content-hash keyed paths must not allow path traversal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05W1-01 | Tampering | np.load on .embeddings.npy sidecar (numpy binary format) | mitigate | Use `np.load(path, allow_pickle=False)` — disables pickle deserialization. Only loads the float32 array, no arbitrary Python objects. If allow_pickle=False raises on a poisoned file, catch and fall back to _search_legacy with a warning. |
| T-05W1-02 | Tampering | json.loads on .chunks.json and .bm25.json | mitigate | json.loads is safe (no code execution). Validate loaded shape after deserialization: chunks must be a list of dicts with required keys; bm25 must be a list of lists of str. Reject and fall back to _search_legacy on schema mismatch. |
| T-05W1-03 | Elevation of Privilege | Path traversal via malicious content_hash in sidecar path | accept | Content hash is a hex string produced internally by Blake2b over file bytes; it is never user-controlled. ingest.store._UNSAFE regex already sanitizes keys. No external input reaches the path construction. |
| T-05W1-04 | Denial of Service | Stale or mismatched sidecar (version mismatch) | mitigate | If any sidecar fails to load (wrong shape, missing key, version field mismatch), fall back to _search_legacy and log a warning. Never crash search_corpus on sidecar load error. |
</threat_model>
