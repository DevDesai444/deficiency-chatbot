<objective>
Build the instrument that makes a NO-GO diagnosable. CONTEXT.md's framing for this whole area: *"An un-diagnosed NO-GO wastes the spike."* A gate result without a diagnosis cannot tell you whether to swap the model, fix the loop, or abandon the approach — so the five signals are as much the deliverable as the number.

Three things here have **no analog anywhere in this repo** (PATTERNS.md § No Analog Found) and need extra care:
1. **A JSONL append-stream writer.** `grep -rn "jsonl\|JSONL" src/ tests/ --include=*.py` returns nothing. All existing persistence is whole-file (`store.write_doc_cache`, `run._write_metrics`) or SQLite. The atomic temp-then-rename convention **cannot** apply to an append stream — its failure mode, a truncated final line on an aborted run, must be handled by the reader.
2. **Git-SHA provenance capture.** `grep -rn "subprocess\|git rev-parse" src/ --include=*.py` returns nothing — no module in `src/` shells out or reads git state. A new helper is required and it must degrade gracefully: a missing SHA is a *recorded* `""`, not a crash.
3. **The summary must be written atomically.** `_write_metrics` (`evals/run.py:128-131`) uses `out.write_text` directly and is **not** atomic — a half-written summary is indistinguishable from an aborted run, which is the exact ambiguity D-TEL1(i) exists to prevent. Do not copy that flaw; use `store.write_doc_cache`'s temp-then-`os.replace`.

Purpose: D-TEL1(ii) requires the verdict to be re-derivable from committed files by someone who did not watch the runs. That is only true if the artifacts are complete, provenanced, and honest about abortion.
Output: `TurnLog` and `RunSummary` with all five signal groups, atomic summary writes, and tests that prove provenance completeness and aborted-vs-completed distinguishability.
</objective>

**D-TEL3's matrix — the reading is pre-registered and the two halves are never summed:**
- `half="submission"` + `not_byte_exact` ⇒ **SPAN INVENTION** (model fabricated or retyped a corpus quote). Grounding-discipline failure.
- `half="rule"` + `not_retrieved_this_session` ⇒ **NEVER CALLED `read_guideline`** (model asserted a rule without reading it). Loop-behavior failure.
These imply **different NO-GO remedies** (swap the model vs. fix the loop), so the summary reports the full matrix and the report must name which pattern dominated.

**D-LOOP5's corollary — the two failure layers that must not conflate:**

| Layer | Where | Turn consumed? | Bucket |
|---|---|---|---|
