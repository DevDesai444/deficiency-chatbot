<objective>
Enrich the rulebook and requirement index from their thin Phase-2 baseline (ich=4 chunks;
15 index entries, almost all family 3.2.S.4.3/ICH Q2) to per-requirement granularity, so the
index the Plan-03 absence enumerator walks is no longer sparse. This is RULES-06 (SC1).

Purpose: Absence detection is a rulebook-enumeration problem — you cannot read what is not
present. The index must FIRE ≥1 entry per absence_of_evidence eval deficiency (the traceability
floor, D-ENR1) and generalize past the exact eval spans by decomposing the guidelines those
families live in per-requirement.

Output: Q1A(R2) vendored + ingested; Q3A/Q3B/Q6A decomposed to per-requirement index entries;
expanded profile_requires_family closure edges; a recorded, ratcheted coverage baseline; a
coverage-gate CLI subcommand carrying the traceability check.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vendored rulebook source → local store | ICH/FDA PDFs fetched once from database.ich.org; a swapped/corrupted source would inject false rule text |
| LLM-drafted index entry → committed index | D-ENR4 LLM drafts can hallucinate an ungrounded citation/family |

This is an OFFLINE, on-prem, deterministic build pipeline — no runtime network endpoints, no untrusted
user input, no auth surface. Web-app threats (XSS/CSRF/SSRF/injection at a served endpoint) do not apply.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | vendored Q1A(R2) PDF | mitigate | build.py computes + stores sha256 in rulebook/manifest.yaml with a date-pinned URL (RULES-04); a substituted PDF changes the sha256, surfacing in the committed manifest diff |
| T-04-02 | Spoofing | LLM-drafted requirement_index entry | mitigate | load_requirement_index loader gate re-opens every provenance_span_id byte-exact via open_span and rejects any family not in the D-05 registry — an ungrounded LLM entry RAISES at LOAD/CI, never enters the index |
| T-04-03 | Information disclosure / license | ICH copyright | mitigate | ICH_LEGAL_NOTICE stored per chunk by _ingest_and_persist (license compliance, RULES-04) |
| T-04-04 | Repudiation | index/edge change without version bump | mitigate | REQUIREMENT_INDEX_VERSION bump + changelog comment (D-24) makes every index change auditable in the diff |
</threat_model>
