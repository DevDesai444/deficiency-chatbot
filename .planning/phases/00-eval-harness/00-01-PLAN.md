       `ABSENCE_OF_EVIDENCE = "absence_of_evidence"`, `DERIVATION_PLAUSIBILITY = "derivation_plausibility"`,

       (True == "the detector already finds this; the zero-TP-lost gate must never lose it").
    4. `class EvalDocument(BaseModel)` fields: `doc_id: str`, `path: str` (repo-relative),
       `format: Literal["pdf","docx"]`, `held_out: bool = False`.
    5. `class EvalSet(BaseModel)` fields: `documents: list[EvalDocument]`, `deficiencies: list[GroundTruthDeficiency]`,
       plus helper methods `def families(self) -> set[FailureFamily]` and `def tp_required(self) -> list[GroundTruthDeficiency]`.
    6. `def load_eval_set(dataset_dir: str | Path = None) -> EvalSet`: default dataset_dir = the `dataset/` folder next to schema.py (`Path(__file__).parent / "dataset"`). Read `documents.json` (a JSON list of EvalDocument dicts) and glob ALL `*.deficiencies.json` files in the dir (each a JSON list of GroundTruthDeficiency dicts), concatenate, and validate into an EvalSet. Globbing (not a hardcoded file list) is required so Plan 02 can add documents without editing this file.

    Do NOT import anything from `agents/` or hit the network — this module is pure data + pydantic.
