<objective>
Build the deterministic scoring engine: match detector findings to ground-truth deficiencies with
NO LLM, then compute end-to-end precision/recall BY FAILURE FAMILY plus the five per-stage metrics
required by EVAL-02. Capture the existing run-3 estradiol detector output as a committed golden
fixture so every metric is reproducible in CI without invoking a model.

Purpose: This is the instrument PITFALLS.md #1/#11 demand — recall-by-family is the milestone's
primary metric, and it must be computed by code, not asserted. Matching is code-grounded (mirrors
verify.py::_anchored substring discipline) so a paraphrased finding cannot be credited as a hit.
Output: `src/evals/match.py`, `src/evals/capture.py`, `src/evals/metrics.py`, the golden fixture,
and unit tests pinning the 2-of-28 baseline.
</objective>

  <behavior>
    - A detector Fault whose evidence+title+detail (same doc) contains ALL distinctive anchor tokens of a GT deficiency -> that GT id is matched (TP).
    - The Table-20 finding (evidence contains "11477" and "12601") matches GT "C-01"; the 0.15%-impurity finding matches "C-02".
    - A finding matching no GT deficiency -> counts toward FP. A GT deficiency matched by no finding -> FN.
    - Matching is many-to-one collapsed: N findings hitting the same GT id count as 1 TP for recall (dedup), but FP counting still sees unmatched findings.
    - Normalization: lowercase, strip spaces and `%`, so "0.15 %" and "0.15%" both contain token "0.15".
  </behavior>
  <action>
    Create `src/evals/match.py`:
    - `def _norm(s: str) -> str`: lowercase, remove whitespace and `%` signs.
    - `def _anchor_tokens(anchor: str) -> list[str]`: split the GT `evidence_anchor` into distinctive tokens — numeric/identifier runs (regex `[0-9][0-9.\/]{2,}` plus any word >=6 chars). Return the normalized tokens; a deficiency needs its tokens present to be credited.
    - `def finding_text(fault: dict) -> str`: normalized concatenation of fault["evidence"], fault["title"], fault["detail"].
    - `def matches(fault: dict, gt: GroundTruthDeficiency) -> bool`: True iff `gt.doc_id` equals the run's doc_id AND every token from `_anchor_tokens(gt.evidence_anchor)` appears in `finding_text(fault)` (require >=1 token; if the anchor yields 2+ tokens, all must appear — prevents a single common number matching everything).
    - `def score(faults: list[dict], gts: list[GroundTruthDeficiency], doc_id: str) -> MatchResult` where `MatchResult` (a small dataclass or pydantic model) carries `matched_gt_ids: set[str]`, `tp_findings: list[int]` (indices), `fp_findings: list[int]`, `fn_gt_ids: set[str]`.

    Create `tests/evals/test_match.py` pinning: a fault dict with evidence "Maximum: Theoretical plates: 11477 ... In-house Equivalency Study: 12601" matches the C-01 GT and NOT an unrelated GT (e.g. a regulatory-framing item); a fault with "unspecified impurity 0.15% ... NMT 0.10%" matches C-02; a paraphrase with no anchor tokens does not match.
  </action>
  <acceptance_criteria>
